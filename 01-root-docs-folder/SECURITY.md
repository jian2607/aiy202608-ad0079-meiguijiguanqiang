# 安全政策

## 支持范围

当前维护版本为仓库默认分支上的最新代码。项目仍处于本地研究工具阶段，不应直接暴露在公网，也未提供多用户身份认证和权限隔离。

## 报告安全问题

优先使用GitHub仓库的 Private vulnerability reporting；如果该功能未启用，请通过仓库所有者提供的私有联系方式报告漏洞。不要在公开Issue、Discussion、日志或截图中提交以下信息：

- DeepSeek或其他第三方服务密钥；
- 未脱敏的公司财务数据和上传文件；
- 本地数据库、访问令牌、Cookie或系统路径中的个人信息。

报告中请包含受影响版本、复现步骤、影响范围和建议修复方式，但使用无敏感信息的最小示例。

## 密钥处理

- 密钥仅存放在本地 `.env` 或部署平台的秘密变量中；
- 前端代码、Git历史、Issue和构建产物中不得出现密钥；
- 怀疑密钥泄漏时，应立即在服务商后台撤销并重新生成；仅从文件或Git历史中删除并不能使旧密钥失效；
- 提交前应检查暂存区，确认 `.env`、数据库、日志和生成数据未被纳入提交。

## 部署边界

Flask开发服务器只用于本地开发。对外部署前至少需要增加生产级WSGI服务器、HTTPS、身份认证、访问控制、上传内容校验、速率限制、审计日志和秘密管理。
